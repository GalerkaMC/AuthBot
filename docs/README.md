# Документация REST API

Эта директория содержит документацию для REST API сервиса AuthBot.

## Файлы документации

- `api.yaml` - Спецификация API в формате OpenAPI 3.0

## Использование

Спецификацию можно просмотреть с помощью любого инструмента, поддерживающего OpenAPI, например:

- [Swagger UI](https://swagger.io/tools/swagger-ui/)
- [ReDoc](https://github.com/Redocly/redoc)

## Эндпоинты

1. `GET /api/v1/health/` - Проверка работоспособности сервера
2. `POST /api/v1/2fa/` - Запрос на авторизацию с параметрами:
   - `userId` - айди игрока в мессенджере
   - `nickname` - никнейм игрока
