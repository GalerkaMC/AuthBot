# AuthBot

Telegram-бот для двухфакторной аутентификации на сервере.  
Представляет собой микросервис.

## REST API

Взаимодействие с сервисом осуществляется через REST API.  
Документация к API расположена в директории [/docs](./docs).

> ⚠️ **Важно:**  
> API не является публичным. Порт, на котором работает сервис, должен быть закрыт извне.

## Принцип работы

Сервис реализует механизм двухфакторной аутентификации (2FA).  
При попытке входа на сервер пользователь должен подтвердить вход через Telegram-бота.

### Последовательность действий:

1. Сервер отправляет запрос к REST API сервиса.
2. Сервис ожидает подтверждение входа от пользователя через Telegram-бота.
3. После подтверждения сервис отправляет обратный запрос на REST API сервера, разрешая пользователю войти.
